# Experiment 002: The Flanker Effect

## Research Question

Does conflicting visual information affect response
accuracy and reaction time in a selective attention task?

## Independent Variable

Trial congruency:
- Congruent: surrounding arrows point in the same
  direction as the target arrow.
- Incongruent: surrounding arrows point in the
  opposite direction to the target arrow.

## Dependent Variables

1. Response accuracy: whether the participant
   correctly identifies the centre arrow's direction.
2. Reaction time: time taken to respond, measured
   in milliseconds.

## Hypotheses


## Hypotheses

### 1. Response Accuracy

Null Hypothesis (H₀):
There is no difference in mean response accuracy
between congruent and incongruent trials.

Alternative Hypothesis (H₁):
Mean response accuracy will be lower in
incongruent trials than in congruent trials.

### 2. Reaction Time

Null Hypothesis (H₀):
There is no difference in mean reaction time
between congruent and incongruent trials.

Alternative Hypothesis (H₁):
Mean reaction time will be longer in
incongruent trials than in congruent trials.
  
## Experimental Design

Design: Within-subjects experiment.

Each participant completes both congruent
and incongruent Flanker trials.

Trial order will be randomised to reduce
systematic order effects.

The experiment will measure response accuracy
and reaction time for each trial.

## Experimental Procedure

1. The participant reads the task instructions.
2. A fixation cross (+) appears for 500 milliseconds.
3. Five arrows appear on the screen.
4. The participant identifies the direction of the
   centre arrow using the left or right arrow key.
5. The experiment records:
   - Trial condition (congruent or incongruent)
   - Correct response
   - Participant response
   - Response accuracy
   - Reaction time in milliseconds
6. The next trial begins.

Both conditions will be presented in random order.

## Trial Structure

Practice Phase:
- 8 practice trials.
- Participants receive feedback on their responses.
- Practice data will be excluded from the main analysis.

Experimental Phase:
- 40 trials in total.
- 20 congruent trials.
- 20 incongruent trials.
- Trials presented in random order.
- No correctness feedback during experimental trials.

The experimental trial count is provisional
and intended for prototype development.

## Statistical Analysis Plan

### Response Accuracy
- Calculate the percentage of correct responses
  for each experimental condition.
- Compare accuracy between congruent and
  incongruent trials.

### Reaction Time
- Include correct-response trials only.
- Calculate mean reaction time for each condition.
- Compare congruent and incongruent trials.

### Statistical Testing
- Calculate condition-level summaries for each participant.
- For a future multi-participant study, consider
  paired-samples t-tests for the planned comparisons,
  subject to checking assumptions.
- Report effect sizes and confidence intervals.
- Use a significance threshold of alpha = 0.05.
- Account for testing two outcomes in the final
  inferential analysis plan.

### Data Exclusions
- Exclude practice trials.
- Exclude incorrect responses from reaction-time analysis.
- Define additional exclusion criteria before analysing data.

### Research Limitations
- Prototype testing does not establish psychological effects.
- Synthetic data will be used only to validate the system.
- Human-participant research requires appropriate ethical
  and methodological review before recruitment.
